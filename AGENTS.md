# AGENTS.md

## Code style
- Write the simplest code that works. No clever tricks, no extra abstractions.
- Don't add comments to code.
- After each code block, explain in plain words what it does so the user can write their own comments.

## Files
- Only create a new file when you actually need one. Otherwise edit the existing one.
- Don't add boilerplate, unused helpers, or placeholder code.
- Keep files small. If something can be deleted without breaking anything, delete it.

## Changes
- Touch only what the task needs. Don't refactor or reformat unrelated code.
- Don't add dependencies unless there's no reasonable way around it.
